## What it is

A SwiftUI and SwiftData app in which every message is a node with a parent, children, and a remembered child — the branch the app follows by default. A tree holds its root, its current position, its bookmarks and its model settings; you can stream from Anthropic or OpenRouter, branch from any point, and export the whole structure as OpenLoom, the interchange format that now lives with Aspen Grove.

## What is happening to it

The first pass of a finish-it session has landed: the two data-loss bugs (an export that re-parented nodes into a phantom tree, a delete rule that cascaded upward) are fixed with tests, the read path no longer writes, and the view layer no longer persists every keystroke or re-highlights every code block on every streamed token. The repo went from no tests to twenty.

## Where it ends

This is being shipped as a finished 1.0 with a maintenance floor — builds kept green, model lists refreshed, no new features. Active loom development is Aspen Grove; two clients on one format would only drift apart. The spec they share is [OpenLoom](/products/aspen-grove/open-loom).
