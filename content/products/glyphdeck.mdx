GlyphDeck is a handheld gaming platform that exists entirely in software. Its display is text — every game it runs is built against that constraint rather than around it, and the platform's own tooling is built to make working inside that constraint fast rather than punishing.

The platform ships with native performance, local multiplayer, and a companion app that runs on the same device as the games themselves. The games it runs exist nowhere else — GlyphDeck is the only place to play them.

It is in development. The site linked above carries whatever is public today.
