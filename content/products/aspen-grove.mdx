Aspen Grove is a mobile interface for large language models that treats a conversation as an explorable tree instead of a single linear thread — branch, backtrack, and compare alternate responses to the same prompt instead of losing every path but the one you kept. It's built local-first on React Native and WatermelonDB, with a Clean Architecture split between domain, application, infrastructure, and interface layers, and a provenance system that hashes and chains every model response as it arrives.

## OpenLoom

OpenLoom is a JSON interchange format for loom trees — the branching, multi-author explorations of language-model output this app and others like it are built around — designed so a tree created in one loom can be opened in another without losing its structure, its authorship, or its provenance. Aspen Grove is where the format originates, and the full draft specification is documented separately.
