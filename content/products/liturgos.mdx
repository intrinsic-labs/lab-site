Liturgos is worship-planning software for NAPARC (North American Presbyterian and Reformed Council) churches, built around one idea: a shared set of reusable liturgy elements that a service is assembled from, rather than a fresh document written each week.

Because the elements are structured data rather than prose in a file, everything downstream — bulletins, slides, and a searchable history of what's been used and when — falls out of the same source instead of being retyped for each format.

It retrieves, remembers, and formats. It never writes worship content — the judgment about what a service should say stays with the people planning it.

It is in development. The site linked above carries whatever is public today.
