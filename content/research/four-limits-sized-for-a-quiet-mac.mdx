Our agents share one Mac, and on November 11 and 12 many of them ran test suites at once, with the load average near 200. Four limits that had been sized on a quiet machine failed, each in a different way.

**A failed listing read as an empty one.** When an agent run ends, a sweep kills the processes it left behind. It listed processes once, with `ps` limited to 3 s. Under load the call timed out, and the sweep treated that as nothing to kill. It also looked only once, so a daemon that forked mid-shutdown was never seen. Now each listing gets 10 s and up to three tries, and the sweep lists again after the grace period. Run 320 times, 20 in parallel beside 12 CPU burners, the test file went from 2 failures to 0.

**A passing verify was killed.** Before our automation switches to a new commit, it runs the full test suite. That run had inherited the 5-minute limit meant for a single git call. Healthy runs took 127 to 275 s in November, so under load the limit killed two runs that were passing. The verify now has its own 15-minute budget.

**A shim found itself.** Agents reach GitHub through a `gh` script early on their PATH, which looks up the real `gh` on PATH. It skipped only its own copy, so a test run with different settings found the live shim, took it for the real one and called back in. Two chains reached about 4,000 processes, 86 GB of swap and 1% free disk before they were killed. Every copy now carries a marker, and a re-entry variable stops a call that comes back. The marker alone was not enough: a hand-made wrapper without it caused the same loop the next day, so any wrapper now counts.

**A version probe never returned.** Two tests ran `codex --version` with no timeout to see whether the CLI was installed. Twice on November 12 it hung whole test runs for over 30 minutes. Every probe now has a 10 s timeout.

## What we'd tell someone doing the same

- Treat a failed listing as a failure, never as an empty result, and list again after the grace period.
- Give a full-suite verify its own time budget, not the per-command default.
- Guard any shim found on PATH against finding itself: recognise every copy, and set a re-entry variable it refuses to run under.
- Time out every version probe.
