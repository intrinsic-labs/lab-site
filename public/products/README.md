# Product images

One folder per product slug (`tycho/`, `vault/`, …). Drop screenshots here;
`hero.png` (or .jpg) is used on the product card and at the top of the product page,
and any other files in the folder are shown as a gallery on the product page in
filename order (`01-…png`, `02-…png`).

Tycho: the capture harness output goes in `tycho/`. Dark UI screenshots suit the dark
dossier page.
